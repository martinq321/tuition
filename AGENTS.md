# Maths Wednesdays

Treat a bug report on one activity as a report about the whole site. Identify what causes it, find every page and pupil variant that uses that component or pattern, then fix the common source and verify the affected routes. Use the device and input method named in the report and record which checks were simulated or run on physical hardware. Preserve intentional differences between activities. See [CONTRIBUTING.md](CONTRIBUTING.md) for the workflow and release checks.
