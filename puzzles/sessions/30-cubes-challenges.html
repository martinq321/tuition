    For educators · what each task means

    1: height 1, four shapes up to rotation. 2: no edge shorter than 2, so only 2×3×5. 3: maximum edge 10, so 1×3×10, 1×5×6 and 2×3×5. Each uses exactly 30.

    4: compare the five cuboids. Outside-face counts are 122, 94, 86, 82 and 62 respectively. The 2×3×5 cuboid uses least wrapping. This is a surface-area investigation with fixed volume, not a request to make a larger block.

    Begin with one rule. Only use the wrapping extension after counting faces on real blocks. Ask pupils to explain why a shape meets a rule before pressing Check.
