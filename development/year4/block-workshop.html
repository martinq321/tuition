Ideas to investigate together

Make one group using only ones and another using tens and ones. Can they have the same value but different numbers of objects?

Before exchanging, predict: what will change? What will stay the same? Try exchanging back again.

For 36 × 3, Alice splits 36 into 30 + 6. Bob uses 40 − 4. Use the blocks to explain both approaches.

Off-screen: use labelled paper counters or squared-paper strips. In sweets mode a pack contains ten sweets, and a box contains one hundred.
